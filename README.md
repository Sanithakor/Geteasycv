# GetEasyCV - Professional Resume Builder

A modern, professional resume builder built with Next.js, TypeScript, and Tailwind CSS. Create beautiful, ATS-friendly resumes with 200+ template combinations and export as high-quality PDFs or images.

## 🚦 Getting Started

### Prerequisites
- **Node.js 18+** - [Download](https://nodejs.org/)
- **npm** or **yarn** - Package manager
- **Git** - Version control

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/geteasycv.git
   cd geteasycv
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Start development server**
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000)

### Build for Production

```bash
# Build the application
npm run build

# Start production server
npm start
```

## 🎨 Architecture Overview

### Template Generation System

The core architecture follows the pattern:
**LAYOUT + THEME + SECTION VARIANT = TEMPLATE**

```typescript
// Example template generation
const template: GeneratedTemplate = {
  id: 'modern-card-teal',
  layout: modernCardLayout,      // Structure and positioning
  theme: tealTheme,              // Colors, fonts, styling
  sectionVariants: {             // Component variations
    headerVariant: 'centered',
    experienceVariant: 'timeline',
    skillsVariant: 'progress-bars'
  }
};
```

### Component Hierarchy

```
TemplateRenderer
├── Layout Component (e.g., ModernCardLayout)
│   ├── Header Section
│   ├── Summary Section
│   ├── Experience Section
│   ├── Education Section
│   ├── Skills Section
│   └── Additional Sections
└── Theme Provider (colors, fonts, spacing)
```

## 🔧 Configuration

### Adding New Layouts

1. Create layout component in `components/cv/layouts/`
2. Define layout configuration in `data/layouts.ts`
3. Export from `components/cv/layouts/index.ts`
4. Templates will be auto-generated with all themes

### Adding New Themes

1. Define theme object in `data/themes.ts`
2. Templates will be auto-generated with all layouts

### Customizing Export Options

Edit `lib/exportUtils.ts` to modify export presets:

```typescript
export const exportPresets = {
  draft: { quality: 0.8, scale: 1.5 },
  standard: { quality: 0.95, scale: 2 },
  high: { quality: 1.0, scale: 3 },
  print: { quality: 1.0, scale: 3, format: 'a4' }
};
```
